# API 参考

以下接口仅用于文档展示，不提供真实服务。主要目的是练习如何在 MkDocs 中编写接口文档。

## 查询文档列表

- **请求方法**：GET
- **请求路径**：/api/docs
- **功能**：返回文档条目列表，支持分页和关键词搜索

### 请求参数

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| page | int | 否 | 页码，默认 1 |
| size | int | 否 | 每页条数，默认 10 |
| keyword | string | 否 | 搜索关键词 |

### 返回示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 4,
    "page": 1,
    "size": 10,
    "items": [
      {"id": 1, "title": "使用指南", "url": "guide.md"},
      {"id": 2, "title": "关于本项目", "url": "about.md"},
      {"id": 3, "title": "API 参考", "url": "api.md"},
      {"id": 4, "title": "首页", "url": "index.md"}
    ]
  }
}
```

## 获取单篇文档详情

- **请求方法**：GET
- **请求路径**：/api/docs/{id}
- **功能**：根据文档 ID 获取完整内容

### 路径参数

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| id | int | 是 | 文档 ID |

### 返回示例

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "title": "使用指南",
    "content": "# 使用指南\n\n本文档介绍如何...",
    "created_at": "2026-11-01T00:00:00Z",
    "updated_at": "2026-11-09T00:00:00Z"
  }
}
```

## 错误码说明

| 错误码 | 说明 |
| --- | --- |
| 0 | 成功 |
| 4001 | 参数错误 |
| 4040 | 资源不存在 |
| 5000 | 服务器内部错误 |
